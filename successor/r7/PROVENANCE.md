The experiment uses programmatic provider interfaces with Python 3.12 and pinned `cryptography==50.0.2`, `cffi==2.1.1`, `pycparser==3.12`. The build uses `setuptools==80.9.0` and `wheel==0.45.1`. These are exact version pins, not a claim that every dependency archive has a recorded provenance or hash lock. No new MCP SDK package, transport, OAuth deployment or model is added by this lot.

Preserve distinct identities for the source head and tree, wheel bytes, actually loaded installed package files, frozen inputs, each execution's processes and SQL backup, exported archive and downloaded release asset. A declared Git SHA alone is insufficient. The CI `BUILD.json` records the actual checkout, ordered parents and tree, source-file map, wheel hashes and installed-package map; campaign `SOURCE.json` measures the loaded package. Read these together. Installed execution outside a checkout may legitimately have no Git worktree identity in `SOURCE.json`; its package hashes must still link to the build receipt.

All 24 pairs in one full campaign reuse 12 authored templates. Data-only export audits, selected installed smokes and separate diagnostic controls are different evidence categories. Repeating a platform, relabeling a checkout, receiving an AI review or hashing a ZIP does not create independent human reproduction, security certification or standards adoption.

Failed/partial runs, operational errors, pre-correction sources and prior decisions remain retained. A corrected source receives its own identity; prior output is not rewritten as a successful run. R1 and R2 describe what their reviewers actually inspected or executed, and explicitly retain same-team AI-review limitations.

Release work is conditional on the matching gates. Windows results keep candidate-H attribution; CI on actual merged M and a final installed package smoke keep M attribution. The public prerelease, if completed, must expose exact sources and reviewed data, permit a fresh reader to recompute verdicts, and survive actual anonymous asset download/hash checks. This file does not assert that any future campaign, merge or publication has already occurred.
